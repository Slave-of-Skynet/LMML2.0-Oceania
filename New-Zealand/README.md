# New Zealand — The Braided River Run

Search the weighted river state graph for the minimum-time route.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py
```

## Input and output

test-input.txt (or the included training map for practice).

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1oLxH-OAoWxqsFz9UeW6VEdg6Q-6dzGLj).
