# Fiji — Walu Season

Compute the deterministic fishing schedule from the task parameters.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py
```

## Input and output

test-input.json from the organizer runner.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1unO-9zwzs2WuaycH0a9DFkmI9ee-ya8r).
